# 🎯 APP VIBE: Web Berubat Tangerang

## 1. Core Philosophy

- **Modern tapi Familiar:** Mengingat target pasar adalah orang tua (40-60+ tahun), hindari animasi berlebihan, gunakan font ukuran besar (minimal 16px untuk body), kontras warna yang tinggi, dan tombol yang jelas ukurannya (bukan sekadar text link).
- **Aksi Cepat:** Semua ujung corong (funnel) transaksi mengarah ke WhatsApp. Orang tua lebih percaya chat WA langsung daripada sistem *checkout* rumit.
- **Reference:** Desain lama di `.https://web-berubatvercel.app/` tetap dipertahankan *feel* warna dan identitasnya, tapi di-*upgrade* jadi dinamis.

## 2. Tech Stack

- **Framework:** Next.js 16/latest (App Router).
- **Database & ORM:** PostgreSQL + Prisma ORM.
- **Styling:** Tailwind CSS + shadcn/ui (Pilih komponen yang aksesibilitasnya bagus).
- **State Management:** Zustand.
- **Notifikasi:** API Fonnte / Watzap (untuk push notif WA otomatis) + Resend (untuk Email).
- **CMS:** Payload CMS (untuk manage conten seperti blog dsb)
- **Authentication:** NextAuth.js
- **Linting & Formatting:** ESLint & Prettier

# 🚀 ROADMAP

## Phase 1: Foundation & Initial Setup ✅

- Inisiasi proyek Next.js dengan App Router.
- Konfigurasi Tailwind CSS dan instal shadcn/ui.
- Integrasi ESLint dan Prettier untuk konsistensi kode.
- Setup Prisma ORM dengan PostgreSQL sebagai database.
- Implementasi skema database ke `prisma/schema.prisma` berdasarkan definisi di `SCHEMA` section file ini.
- Jalankan migrasi Prisma awal untuk membuat tabel database.
- Konfigurasi NextAuth.js untuk autentikasi admin.

## Phase 2: Refactoring Old UI & Dynamic Content ✅

- Replikasi Landing Page statis lama (Hero Section, Galeri, Layanan) menggunakan komponen shadcn/ui.
- Implementasi *data fetching* untuk section Testimoni dari database (filter `show: true`).
- Pastikan seluruh UI landing page memenuhi kriteria aksesibilitas "Orang Tua" (Font besar, kontras jelas, tombol mudah diakses).
- Tambahkan placeholder untuk link navigasi ke halaman produk dan blog.

## Phase 3: Admin CMS & Dashboard ✅

- Buat halaman login admin (`/admin/login`) dilindungi NextAuth.
- Buat Admin Dashboard (`/admin`) dengan ringkasan data (total booking, produk, testimoni).
- Buat halaman CRUD untuk mengelola Produk Herbal (tambah, edit, hapus, update stok).
- Buat halaman untuk mengelola Testimoni (approve/reject, edit).
- Buat tampilan untuk melihat dan mengelola data Booking (ubah status: PENDING, CONFIRMED, DONE).
- Setup Payload CMS untuk manajemen Blog (title, slug, content, author, publishedAt).
- Buat halaman `/blog` dan `/blog/[slug]` mengambil data dari Payload CMS.

## Phase 4: Booking System & Automated Notifications ✅

- Rancang UI pemilihan tanggal booking sederhana (list tanggal/jam, bukan kalender kompleks).
- Buat UI untuk pemilihan slot waktu yang tersedia.
- Kembangkan formulir pemesanan dengan input Nama dan Nomor WA.
- Implementasi Server Action untuk menyimpan data booking ke database.
- Integrasi API Notifikasi (Fonnte) untuk mengirim pesan otomatis ke WA owner setelah booking baru.
- Integrasi Resend untuk notifikasi email konfirmasi ke user (opsional).

## Phase 5: E-Commerce Herbal (Zustand & WhatsApp Checkout)

- Buat halaman `/herbal` untuk menampilkan daftar produk herbal dari database.
- Implementasi tampilan grid produk dengan pagination/lazy loading jika diperlukan.
- Integrasi Zustand untuk *state management* keranjang belanja (menambah, mengurangi, menghapus produk).
- Buat komponen *floating cart* yang menampilkan item di keranjang.
- Kembangkan fungsi `generateWhatsAppLink(cartItems, total)` yang membuat URL WhatsApp dengan detail pesanan.
- Tambahkan tombol "Checkout via WhatsApp" yang memicu fungsi di atas.

## Phase 6: Finalisasi & Deployment ✅

- Konfigurasi `vercel.json` + `prisma generate` di build script.
- Push ke GitHub: [https://github.com/FathHaq/berubat.git](https://github.com/FathHaq/berubat.git)
- `.env.example` lengkap dengan instruksi Neon, Fonnte, NextAuth.
- Set environment variables di Vercel dashboard (DATABASE_URL Neon, AUTH_SECRET, WA_API_TOKEN).
- Jalankan `prisma migrate deploy` di Neon setelah deploy pertama.
- Jalankan seed admin di production: `npm run db:seed`.
